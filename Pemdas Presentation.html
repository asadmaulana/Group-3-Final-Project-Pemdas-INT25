Background

🎯 The Problem

  • Lack of engaging educational media for memory training
  • Children and adults need fun ways to train cognitive skills
  • Need for combination of entertainment and learning
  • Limited interactive mathematical learning tools

💡 The Solution

Memory Match Game that combines classic card game elements with modern technology, featuring a scoring system and special mode for mathematical skill training. The game provides an interactive and engaging learning experience for all ages.

Main Features

🎲 Game Modes

Easy: 4×4 (16 cards)
Medium: 4×6 (24 cards)
Hard: 6×6 (36 cards)
Nightmare: 4×4 Math

🎨 Multiple Themes

4 different themes per mode: Flowers, Dresses, Disney, FC Teams, Animals, Emoji, and more

⭐ Star Rating System

Star rating (1-3 stars) based on completion time and number of moves

🔥

Nightmare Mode

Special Mathematical Challenge

🔥 Mathematics Integration Mode

Challenge mode combining memory game with mathematical operations

📐 Concept

Cards contain mathematical expressions (2+3, 4+1) that must be matched by their equal results (5)

➕ Operations

Supports addition (+), subtraction (−), multiplication (×), and division (÷)

🎯 Target

Train quick calculation skills while sharpening memory

⚡ Dynamic

Each game generates unique and different mathematical problems
